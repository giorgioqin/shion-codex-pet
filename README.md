# 柳木诗梦 · Codex Desktop Pet

一个非官方纯二创的《甜蜜女友3》柳木诗梦像素桌面宠物包，借助ChatGPT完成，适用于 Codex 桌面宠物。本人之前没有过做这种文件的经验，可能简陋了一些。
灵感来源于抖音博主“@然”发布的“拼豆图纸｜哈基梦”

This is an unofficial fan-made custom pet. It is not affiliated with or endorsed by the game publisher or the character's rights holders.

## 文件

- `shion-pet-v2.zip`：最简单的安装包，内含 `pet.json` 和 `spritesheet.webp`
- `pet.json`、`spritesheet.webp`：宠物清单与 v2 动画图集
- `preview.png`：完整动画行与方向行预览，不属于安装文件

## 安装

1. 下载并解压 `shion-pet-v2.zip`。
2. 将解压出的 `shion` 文件夹放到 `~/.codex/pets/` 下，最终目录应包含 `~/.codex/pets/shion/pet.json` 和 `~/.codex/pets/shion/spritesheet.webp`。
3. 在 Codex 的 Pets 设置中刷新并选择 Shion。

图集是透明背景的 v2 WebP，尺寸为 1536 × 2288 像素。仓库未附带原始带水印参考图。仓库不声明对《甜蜜女友3》或柳木诗梦的权利，也未授予游戏角色相关权利。
